| Field | Desktop | Mobile |
| --- | --- | --- |
| Shape | top nav: one white header bar (z 30, 1px bottom hairline) over the section content; no sidebar. App = 2-row grid: header · main | Phone: 3-row grid header · main · bottom tab bar (`auto minmax(0,1fr) auto`); 52px header; tablet: as desktop (no tab bar) |
| Sidebar width | n/a — no sidebar; every section is reached from the header (pinned tabs + All sections list) | n/a — no sidebar on any viewport; phone uses the bottom tab bar instead |

Keyboard (outside text fields): G opens/closes All sections · 1–9 then 0 jump to the 1st–10th section in list order (Today … Users) · ⌘K / Ctrl K toggles the command menu · / focuses the visible list search · Esc closes the open popover or drawer.

Phone bottom tab bar: `nav` aria-label "Sections", grid of 5 equal columns, height calc(58px + env(safe-area-inset-bottom)), padding 4px 4px env(safe-area-inset-bottom), 1px top hairline, white, z 35. Each slot: column of icon pill (46×28, radius 999, background transition 160ms) + label 10.5px, line-height 1.1, ellipsis; gap 3px; radius 10px; no tap highlight. Slots 1–4 = first 4 pinned sections the role can see (default Appointments · Leads · Patients · Payments), icon 16px. Slot 5 = "More" (aria-label "All sections", `aria-haspopup="dialog"`, Lucide `compass` 18px): when the current section is not pinned its label becomes that section's name and it takes that section's tone (tone bg pill, tone ink, 600); when the current section is pinned it reads "More" and its pill turns z100 while the sheet is open.

## Responsive

| --- | --- |
| < 760px (phone) | header 52px, gap 8px, sides 12px; wordmark hidden (mark only); section chip appears after the logo; All sections button, pinned tabs, "More" and "How data connects" hidden; search collapses to a 36px icon button; bottom tab bar appears as the third app row (58px + safe-area inset); All sections opens as a bottom sheet (max 85vh); every `main` h1 hidden; page gutter 0; tooltips hidden; drawers, pickers, Filters, toolbars and tables switch to the phone patterns in `_patterns.md` |
| 760–1099px (tablet) | header as desktop (60px; logo + wordmark, All sections, pinned tabs with measured "More", full search, "How data connects"); no tab bar; list-toolbar tabs min 120px wide and scroll sideways; list h1 18px; row-action buttons at least 36×36; compact paddings (always < 1440px wide) |
